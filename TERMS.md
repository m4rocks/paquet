Our [Privacy Policy](https://paquet.m4.rocks/privacy) describes how
we handle your information. By using Paquet, you agree to the
Privacy Policy and to these terms and conditions.

## 2. What Paquet is

Paquet is a directory of web apps. The apps listed on Paquet are made and
run by other people. Paquet does not own, operate or endorse them, and is not
responsible for their content, availability, security or privacy practices.
Opening an app takes you to the app's own website, where the app's own terms
apply.

## 3. Using the service

1. Users that find a security vulnerability should report it at once through
   [GitHub](https://github.com/m4rocks/paquet/security/advisories/new).
   Do not expose the vulnerability publicly.
2. Please refrain from using special software that could intentionally
   cause harm or abuse Paquet or its endpoints.
3. Paquet is provided as is, without warranty of any kind. It may change or be
   unavailable at any time.

## 4. Listing apps

1. Anyone can propose an app by following the
   [getting started guide](https://paquet.m4.rocks/docs/getting-started).
2. Paquet may refuse or remove any listing, for example if the app is
   unsafe, misleading, broken or abusive.
3. App owners can ask for their app to be removed by opening an issue on
   [GitHub](https://github.com/m4rocks/paquet/issues).

## 5. The source code

1. The source code of Paquet is available on [GitHub](https://github.com/m4rocks/paquet).
2. You are free to contribute to it at any time, as described in the
   [contributing guide](https://github.com/m4rocks/paquet/blob/main/CONTRIBUTING.md).
3. Do not contribute intentionally malicious code.
